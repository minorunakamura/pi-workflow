# pi-verification

Use this Skill with a fresh built-in `reviewer` for verification.

- Compare the approved scope and acceptance criteria with the actual diff.
- Require runtime verification evidence from the native acceptance contract.
- Report residual risks and missing evidence explicitly.
- Do not modify source files or treat child prose as verification evidence.

The executable verification flow is implemented in later Steps.
