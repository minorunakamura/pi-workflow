# pi-planning

Use this Skill with a built-in `reviewer` when planning a change.

- Keep scope, non-goals, acceptance criteria, WorkUnits, write scopes, risks, and verification explicit.
- Preserve WorkUnit order from the decision contract.
- Do not guess unresolved product, architecture, policy, or risk decisions.
- Return machine-readable `PlanningDecisionV1`; do not edit repository files.

The full Planning Flow and Plan Review gate are implemented in later Steps.
